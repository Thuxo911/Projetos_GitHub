Esse projeto foi realizado

Sistema de terminal com menu interativo.
AS opcoes na tela sao:
1. Adicionar aluno
2. Inserir notas  de um aluno (p1, p2, p3)
3. Calcular media e situacao (aprovado, reprovado por nota ou reprovado por falta)
4. Listar todos os alunos (situacao geral de todos)
5. Creditos
6. Sair

Treinamentos:
Criacao de menus interativos (usando switch case e while)
Uso de enum
Uso excessivo de cin.ignore e cin.clear, para que nao haja problemas quando o usuario for digitar uma resposta pela segunda vez no loop
Criacao e uso de struct
Uso e administracao de vector (push_back, vector no for para percorrer todos os elementos)
O vector "listaAlunos" foi muito utilizado, pois o struct Aluno novoAluno foi utilizado apenas na opcao 1, para inserir o aluno.
Nas outras opcoes, foi usado o vector que guardava dados do tipo "Aluno", e ele foi percorrido usando 
listaAlunos[i].dado
